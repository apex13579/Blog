## Tier 2: Networking Deep Dive (The Anchor)

*Goal: Build deep, vendor-neutral networking knowledge first, then layer on Cisco's vendor-specific implementation.*

**Why this order:** Network+ gives you the universal concepts and vocabulary. CCNA then teaches you how to implement those concepts on real Cisco hardware. Network+ is not a prerequisite for CCNA, but taking it first makes CCNA easier.

- [ ] **CompTIA Network+** — *Vendor-neutral networking fundamentals (OSI model, subnetting, routing, switching, VLANs, troubleshooting)*
- [ ] **Cisco CCNA** — *Vendor-specific implementation (Cisco IOS, device configuration, automation, programmability, security fundamentals)*

> **Summer of CCNA:** This entire parallel track runs while completing Network+ and CCNA. Network Chuck's content will reinforce both.

## Tier 4: Version Control with Git

*Goal: Master Git for version control, repository management, and collaboration. Essential for managing code, tracking changes, and working with GitHub/GitLab in professional environments.*

**Why Git matters for your path:** As you progress through FreeCodeCamp (Tier 6), TCM certifications, and OffSec courses, you will be writing code, tools, and exploits. Git is the industry standard for tracking changes, backing up work, and collaborating. It also appears in penetration testing when assessing CI/CD pipelines and repository permissions.

- [ ] **Programming Foundations: Version Control with Git** — Christina Truong *(Foundational Git concepts: repositories, commits, branching, merging, command line vs. GUI, remote repositories)* [citation:10]

## Tier 9: Associate-Level Offensive Security (TCM)

*Goal: Apply networking, Linux, and scripting knowledge to foundational penetration testing scenarios. These associate certs are prerequisites for professional-level certs.*

- [ ] **TCM PJPT: Practical Junior Penetration Tester** *(Internal network + Active Directory penetration testing. Entry-level red team.)*
- [ ] **TCM PWPA: Practical Web Pentest Associate** *(Entry-level web foundation + bug bounty basics. Prerequisite for PWPP.)*
- [ ] **TCM PAPA: Practical AI Pentest Associate** *(Associate-level AI/LLM penetration testing - prompt injection, jailbreaking, RAG security, OWASP LLM Top 10.)*

## Tier 10: Professional Offensive Security (TCM)

*Goal: Advance to professional-level certifications that test external + internal network penetration testing, advanced web attacks, and require formal report writing.*

- [ ] **TCM PNPT: Practical Network Penetration Tester** *(Professional-level infrastructure exploitation. External + internal network pentesting. DC compromise required. Live client debrief. Prerequisite: PJPT or equivalent experience.)*
- [ ] **CompTIA PenTest+** — *Vendor-neutral penetration testing certification. Renews Security+. Can be taken before or after PNPT.*
- [ ] **TCM PWPP: Practical Web Pentest Professional** *(Professional web specialist - advanced web + API hacking. Prerequisite: PWPA.)*

## Tier 11: Expert-Level Offensive Security (TCM)

## Tier 12: Capstone & Advanced Offensive Security (OffSec)

*Goal: Validate your skills against the most respected practical certifications in the industry. OffSec certs are the gold standard for hands-on penetration testing.*

- [ ] **CompTIA SecurityX** — *Advanced architectural governance and capstone validation. Renews Net+, Security+, and PenTest+.*
- [ ] **OSEP: Offensive Security Experienced Penetration Tester** — *Advanced evasion, C2, and anti-virus bypass.*
- [ ] **OSWE: Offensive Security Web Expert** — *White-box web application security expert.*
- [ ] **OSED: Offensive Security Exploit Developer** — *Windows exploit development from scratch.*
- [ ] **OffSec OSCE³** — *Elite certification for those holding OSEP + OSWE + OSED.*
