# Contributing

Thanks for your interest in contributing to my Pseudo Blog! Whether it's feedback, suggestions, or content ideas, I welcome input to improve the community.

## How to Contribute

### Feedback and Suggestions
- Share ideas for blog topics, streaming schedules, or improvements.
- Report bugs or issues with the site.
- Contact me on Discord for quick discussions.

### Blog Posts
- If you'd like to guest post or suggest content, reach out first.
- Submit via pull request if you're familiar with Git, or send drafts to me.

### Code Contributions
- Fork the repo and submit a pull request.
- Follow the Code of Conduct.
- Keep changes focused and well-documented.

## Guidelines
- Be respectful and constructive.
- Provide details when reporting issues.
- No spam or off-topic content.

For questions, use Discord. Let's build this together!
